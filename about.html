About Me

Saya merupakan lulusan S1 Informatika Universitas Respati Yogyakarta dengan IPK 3,75. Selama menempuh pendidikan, saya mempelajari bidang teknologi informasi dan mengembangkan berbagai proyek berbasis web, sistem informasi, jaringan, AI/ML, serta blockchain.

Profile

Saya memiliki ketertarikan pada pengembangan aplikasi web dan pemecahan masalah menggunakan teknologi. Beberapa proyek akademik saya mencakup sistem informasi, aplikasi chat, speech recognition, dan decentralized application.

Saya juga memiliki pengalaman organisasi sebagai Wakil Kepala Divisi Acara di Keluarga Mahasiswa Katolik (KMK) Universitas Respati Yogyakarta serta pengalaman sebagai Sekretaris 1 dalam KKN Unit 15 Kaliadem.
